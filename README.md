# Wechuntu Outdoor · sitio web

Sitio estático de Wechuntu Outdoor SpA (wechuntu.cl). Publicado en Netlify desde la rama `main`.

- `index.html`: página completa (ES/EN).
- `img/`: fotografías, video y logos.

Para sumar un artículo al blog, editar el arreglo `POSTS` en `index.html`.

Última actualización: 22 de octubre de 2026.
